# Patches Manifest

This directory contains patches generated by `mock_svc` during the instrumentation process. These patches are designed to be applied to `node_modules` after a fresh `npm install` to enable "encounter logging" without permanently forking the dependencies.

## Patches

### `patches/mvsf_instrumentation.patch`

**Target:** `node_modules/@metaversalcorp/mvsf` (specifically `server.js`)

**Purpose:**
Injects NDJSON (Newline Delimited JSON) logging into the core server logic to capture:
1.  **HTTP Requests:** All incoming HTTP requests, specifically to capture access to static resources like `.msf` files.
2.  **WebSocket Connections:** Connection and disconnection events with IP addresses.
3.  **WebSocket Messages:** All incoming Socket.IO events (RPC calls), preserving the event name and payload data.

**Changes:**
- Adds an Express middleware in `LoadHtmlSite` (and similar) to `console.log` request details.
- Replaces standard `console.log` in `io.on('connection')` and `#Handler_IO` with `console.log(JSON.stringify(...))` using the schema `{ at, ua: 'mock_svc', sys, sig, val }`.

## Manual Application

If the patch fails to apply automatically (e.g., due to version changes in the upstream package), follow these steps to manually re-apply the instrumentation:

1.  **Locate `node_modules/@metaversalcorp/mvsf/server.js`**.
2.  **HTTP Logging:** Find where `app.use` is called for CORS or static files. Insert the following middleware before them:
    ```javascript
    app.use ((req, res, next) => {
         console.log(JSON.stringify({ at: new Date().toISOString(), ua: 'mock_svc', sys: 'http', sig: 'req', val: { method: req.method, url: req.originalUrl, ip: req.ip || req.connection.remoteAddress } }));
         // ... existing headers ...
         next ();
    });
    ```
3.  **WebSocket Logging:** Find `io.on('connection', ...)` and the `socket.onAny` handler (usually `#Handler_IO`).
    -   Log connections: `console.log(JSON.stringify({ ..., sys: 'ws', sig: 'conn', ... }))`
    -   Log messages inside `#Handler_IO`: `console.log(JSON.stringify({ ..., sys: 'ws', sig: 'msg', val: { event: sEventName, data: pData ... } }))`

## Verification

After applying, run the server and check `stdout` for lines starting with `{"at":...`.
